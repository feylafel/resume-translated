# resume-translated

Bilingual static resume site (English / 中文) for Christabelle Feyfel Johan.

- Live: https://feylafel.github.io/resume-translated/
- English: `index.html`
- Chinese: `zh.html`
- Theme preference (light/dark) is saved in `localStorage` and shared across both pages.

## Local preview

Open `index.html` or `zh.html` in a browser. No build step or dependencies required.

## Deploy

GitHub Pages is served from the `main` branch root.
